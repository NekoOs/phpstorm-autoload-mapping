Reports recognized PHP files whose existing top-level class declarations and paths do not agree with a configured deterministic autoload mapping.

A mapping combines a base directory relative to the project directory, a class pattern, and a file pattern. For example, {qualified:raw|sep(_)} mapped to {qualified:raw|sep(/)}.php implements the PSR-0/PEAR underscore convention.

Other mappings can express suffix-based files, case transformations, and fixed path literals, such as {class:pascal}_Model mapped to {class:kebab}.model.php.

Global rules apply to global classes. Namespaced declarations participate only when the class pattern explicitly declares namespace structure. Files PhpStorm does not recognize as PHP and PHP files without candidate declarations are ignored.
