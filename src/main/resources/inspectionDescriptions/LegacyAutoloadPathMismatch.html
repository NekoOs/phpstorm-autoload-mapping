Reports top-level global PHP classes whose names and file paths do not agree with a configured deterministic legacy autoload mapping.

A mapping combines a project-relative source root, a class pattern, and a file pattern. For example, {qualified} mapped to {qualified:underscorePath}.php implements the PSR-0/PEAR underscore convention.

Other mappings can express suffix-based files, case transformations, and fixed path literals, such as {class}_Model mapped to {class:kebab}.model.php.

This inspection only applies to top-level global classes covered by configured mappings. It ignores namespaced PHP classes and does not replace PhpStorm's modern PSR-4 inspections.
